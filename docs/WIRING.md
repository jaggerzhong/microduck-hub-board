# 接线说明

## 一、这块板到底在做什么

HD1910 是**串联总线**舵机：所有舵机、IMU、HAT 其实是并联挂载在同一条三线总线（DATA / VBAT / GND）上的，控制器靠 ID 点名，不靠物理位置区分。
所以这块 HUB 不是什么"交换机"或"信号中继"，它就是**一个物理分线器**：把一条总线拆成四个口，外加一个电池输入口和一个总电容。

这也是为什么它上面没有任何芯片：不需要，也不能有。任何有源器件（缓冲器、隔离器、二极管）都会让总线电平变形，反而可能导致丢包。

```text
                        ┌────────────────┐
   2S 电池  ───────────►│ BAT  (2P)      │
   (7.4 V)              │                │
                        │  Microduck     │
   ZERO 3W ── HAT ─────►│ HAT   IMU      │◄──── 躯干 IMU 板
                 │      │                │
                 │      │ LLEG  RLEG     │
                 │      └───┬───────┬────┘
                 │          │       │
        头颈舵机链 ◄────────┘       └──────► 左腿 / 右腿舵机链
```

一句话：**电池进 BAT，HAT 进 HAT，IMU 进 IMU，两条腿进 LLEG / RLEG。**

> HAT 上一般有两个 3P 舵机口（J13 / J14）：一个接 HUB 的 HAT 口，另一个接头颈那条链。
> 哪个是哪个以你手上那块 HAT 的丝印和官方文档为准，本仓库不做假定。

## 二、四个口的针序（重点）

四个 3P 口**不是同一个朝向**，引脚 1（DATA）在两个口上朝上、另外两个口上朝下。板上每个口旁边都印了口名和一个数字 `1`。

| 端口 | 位置 | pin1（DATA） | pin2（VBAT） | pin3（GND） |
| --- | --- | --- | --- | --- |
| HAT | 左上 | 最上 | 中 | 最下 |
| IMU | 右上 | 最下 | 中 | 最上 |
| LLEG | 左下 | 最上 | 中 | 最下 |
| RLEG | 右下 | 最下 | 中 | 最上 |

**接线的唯一依据是丝印上的那个 1**，不是插头塑料壳的防呆方向，也不是"上次那根线"。
不同批次的成品线、不同厂家的 AMP2.0 插头，防呆凸起和针序的对应关系并不统一；靠防呆方向插，很容易把 VBAT 和 GND 对调——那一刻就是烧板子。

### 做线之前先量一遍

拿一根成品舵机线，万用表通断档：

1. 红笔点插头里确定是 DATA 的那一针（看插头侧面的箭头或线序图），黑笔分别点线材另一头的三根，响的那根就是 DATA。
2. 同样方法确认 VBAT、GND。
3. 把这三根的**实际**顺序记下来，再决定插到 HUB 哪个方向。

如果线材两头都是同一种插头（比如都是母头），更简单：直接对着 HUB 丝印 1 号针插。插不进去说明方向反了，**不要削掉防呆硬插**。

## 三、电池这路

BAT 口在顶面，2P，左 = GND（−），右 = VBAT（+），旁边丝印有 `+`。

- 用 2P 插头（EH2.5 / XH2.54）接电池，或者直接把电池两根线焊进这两个孔。
- 上电前用万用表确认极性。**反接会直接烧掉 ZERO 和舵机**，这块板没有任何反接保护。
- 板上没有保险丝。如果希望"某一路短路不要拖垮整机"，可以在电池正极串一个 5 A 左右的自恢复保险丝（PPTC），位置放在 BAT 口和电池之间。

## 四、电容

C1 是 1000 µF / 16 V 电解电容，装在底面，正极接 VBAT、负极接 GND（板上 `+` 号标注）。

它的作用是**吸收 15 个舵机同时启动时的瞬时电流**，避免总线电压瞬间跌落导致 ZERO 3W 重启。不加电容板子也能跑，但急停、起身这类大动作时更容易掉压重启。

## 五、没有第五路怎么办

官方只有四路。要加第五路（比如额外的传感器），直接把线焊在 HAT 口那三个焊盘上——网络完全一样，等价于多并一路。

## 六、上电顺序

1. 不接电池、不接舵机，先用万用表做一遍 [自检表](ASSEMBLY.md)。
2. 接电池，量 HAT 口的 pin2–pin3 应为电池电压（2S 约 7.4~8.4 V）。
3. 断电，接 HAT 和舵机，再上电。
