# 焊接与装机

## 一、焊接顺序

1. **C1（1000 µF 电容，底面）**。长脚进标 `+` 的焊盘（x 负方向那个），短脚进另一侧。焊之前先把电容腿掰到跟孔距 3.5 mm 对齐，别硬拧。
2. **4 个 AMP2.0-3P 母座（全部底面）**，塑料口朝下（朝舵机那边），丝印名对着板子上的口名。底面的字是镜像的，翻过来看正好是正的。
3. **CN1 电池座（顶面）**，或者直接把电池两根线焊进孔里。

顺序的理由很简单：底面元件多、板子要翻面，先把小的焊完，最后焊顶面那一个，就不用再翻回来。

## 二、焊完先别通电

- 母座焊之前，先拿一个空插头插一下试松紧，确认方向和高度都合适——焊完才发现插头进不去，拆起来很麻烦。
- 母座是插件料，焊盘只在底面；顶面对应位置没有焊盘，不要往顶面捅锡。
- 用放大镜或手机微距看一遍相邻焊盘之间有没有连锡，尤其是母座中间那根针，间距小。

## 三、装机

板子平放在左右两个髋舵机外壳顶上、沿中线，4 个母座朝下，用 4 颗 M2 拧进舵机外壳的 Ø1.6 孔位（板上孔距 30 × 16，与外壳同心）。

**必须垫高。** 舵机安装面中间有 Ø16 的出力轴凸台，板子直接贴上去会顶住：

- 官方结构件按"板面高出舵机顶面 6.3 mm"设计，插上母座后还剩约 2 mm 余量。
- 用 M2 尼龙柱或打印垫块做这个高度，螺丝长度 = 板厚 + 垫高 + 咬入 4~5 mm，板厚 1.0 mm 时约 **M2 × 12**。
- 先把垫块装好，用牙签探一下舵机孔有多深，再按实际值买螺丝。螺丝长了会顶到舵机内部。
- **M2 盘头螺丝头径约 3.8 mm，会压到旁边的 GND / VBAT 铜皮**（最近处只有 0.34 mm）。用尼龙垫圈最省事，或者直接用 M2 尼龙螺丝。

电容装底面，吊在两个髋舵机之间的缺口里。板下到髋舵机顶面只有约 2.3 mm，所以优先买 8 × 8 mm 的矮电容；只有 8 × 11.5 mm 的话，装之前量一下通道够不够深。空间紧也可以把电容翻到顶面，顶面 C1 旁边那个 `+` 就是给这种情况标的。

## 四、上电前用万用表过一遍

不接电池、不接舵机，万用表打**通断档（蜂鸣档）**，黑笔固定在一个点，红笔点另一处：

| 测点 A | 测点 B | 应该是 |
| --- | --- | --- |
| HAT 的 1 号 | IMU / LLEG / RLEG 的 1 号 | 全通（DATA 母线） |
| HAT 的 2 号 | BAT 右边、C1 的 + 焊盘 | 全通（VBAT） |
| HAT 的 3 号 | BAT 左边、C1 的 − 焊盘 | 全通（GND） |
| 任意口的 1 号 | 同一个口的 2 号或 3 号 | **不能通** |
| BAT 左边 | BAT 右边 | **不能通**；读数慢慢变大或几十欧是电容在充电，正常 |

最后一条如果直接通（读数一直是 0 Ω），说明有连锡，别上电。

## 五、首次上电

1. 只接电池，不接舵机、不接 HAT。
2. 量 HAT 口 pin2–pin3，应等于电池电压（2S 满电约 8.4 V）。
3. 断电，接 HAT 和一条腿，上电，看 ZERO 能否正常启动。
4. 再逐条接上其余支路。

一次接一条，出问题时能定位到具体是哪一路。

## 六、出问题先查这几处

| 现象 | 优先检查 |
| --- | --- |
| 某一路完全不工作 | 该口母座有无虚焊、插头针序是否反、线材本身通断 |
| 一插上就掉电 / ZERO 反复重启 | 该口 VBAT 与 GND 是否短路，或总电容是否漏电 |
| 总线时通时不通、舵机乱 ID | DATA 线接触不良，母座里那根针松动最常见 |
| 大动作时整机重启 | 电容没焊好或容量不够，也可能是电池内阻太大 |
