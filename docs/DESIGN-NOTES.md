# 设计说明

## 一、为什么是"纯无源"

总线舵机（Dynamixel / Feetech TTL）的 DATA 是**单线半双工**：主机发命令、舵机应答，全挂在一条线上，靠 ID 点名。
这意味着分线板唯一该做的事就是"把同一根线多开几个口"。加任何有源器件都会引入电平偏移、方向切换延迟和失效点，收益为负。

所以这块板上只有三种网络：

| 网络 | 作用 | 走线 |
| --- | --- | --- |
| VBAT | 电池正极，给 15 个舵机供电 | **B 面整层**：两条 1.8 mm 竖干 + 1.5 mm 支线 |
| GND | 公共地，同时是数据回流的参考 | **F 面外圈环**，1.2 mm |
| DATA | 单线半双工总线 | **F 面星形**，从板中心一点扇出到四个口，0.3 mm |

方向也是这么定的：电流从 BAT 进来，向四个口分布，所以电源走线越宽越好，放在整层空着的 B 面；DATA 没有电流，细一点只为了不占地方，放在 F 面。两面各走各的，**没有一个过孔**。

## 二、几何与复核数据

生成脚本每次运行都会跑一遍自检，全部通过才会写文件（日志里的 `CHECK: ok`）：

| 检查项 | 结果 | 规则 |
| --- | --- | --- |
| 铜皮到孔壁最小间距 | 0.34 mm（B 面 VBAT，右下安装孔） | ≥ 0.3 mm |
| 孔心到板边 | 0.9 mm（其余方向 ≥ 2.4 mm） | 够锣边公差 |
| F / B 面不同网络最小间距 | ≥ 0.2 mm | 常规工艺 |
| 铜皮出界 | 全部在板框内缩 0.35 mm 以内 | — |
| 丝印压焊盘 / 出板框 | 无 | — |

钻孔文件两张表：`T1 C1.000`（16 个元件孔）、`T2 C2.200`（4 个 M2 安装孔）。

坐标原点在**板子正中心**，所以所有焊盘坐标都是 ±十几毫米的小数，改尺寸时不用做偏移换算。

## 三、四个安装孔为什么是 30 × 16

依据是 HD1910 规格书第 9 项的图纸：外壳 34 × 20 × 23，四个安装孔 Ø1.6，孔距 30 × 16。
板子长边 34 与舵机对齐、短边 23 比舵机 20 略宽，于是孔中心正好落在 (±8, ±15)，孔心距板边 0.9 mm。

板孔径取 Ø2.2，是为了让 M2 螺丝能穿过去（M2 通孔标准值 2.2，M2 自攻会略紧但也能拧）。

## 四、两个装配上的坑（都在实测中踩过）

1. **必须垫高约 6.3 mm**。舵机安装面中间有 Ø16 的出力轴凸台，板子贴面装会顶住。
2. **螺丝头会压到铜皮**。M2 盘头头径约 3.8 mm，而最近的 GND / VBAT 铜皮离孔壁只有 0.34 mm。用尼龙垫圈或尼龙螺丝解决。这也是为什么 F 面的 GND 环从更外侧的 x = ±7.4 收到 ±5.9：给大孔让出间距，把铜留在孔位内侧。

## 五、版本历史

| 版本 | 说明 |
| --- | --- |
| RevA | 48 × 48 mm 的通用分线板。打印件里放不下——电池仓净宽约 42 mm，壳体轮廓的 45° 方向也超出，废弃 |
| RevB | 照官方外形重画：23 × 34 mm，2 层 1.0 mm，安装孔 4 × Ø1.2、孔距 19 × 30，与官方板一致 |
| **RevC（本仓库）** | 只改安装孔：Ø1.2 → **Ø2.2**，孔距 19 × 30 → **30 × 16**，对齐 HD1910 外壳，全机统一用 M2；GND 环相应从 x = ±7.4 收到 ±5.9。端口、网络、板厚、外形不变 |

## 六、生成脚本

| 脚本 | 作用 |
| --- | --- |
| `tools/gen_hub_v2.py` | 板子的唯一真源：外形轮廓、焊盘、走线、安装孔都在这里；输出 Gerber、钻孔、board.json、pads.csv、preview.png、打包 zip |
| `tools/gen_hub_board.py` | 底层工具：Gerber / Excellon 写入、丝印字形轮廓 |
| `tools/gen_hub_v2_kicad.py` | 把同一份几何导出成 KiCad 5 格式的 .kicad_pcb，可直接导入嘉立创专业版（LCEDA） |
| `tools/hub_v3_servo_check.py` | 把 HD1910 外壳的孔位叠在板上，出 servo-fit.png 对位核验图 |

改孔位只需动 `gen_hub_v2.py` 里的 `NPTH` 一行，然后照 README 的三条命令重出全套产物。
改完记得看一眼生成日志最后的 `CHECK` 行，脚本会替你复核铜到孔的间距、丝印是否压焊盘这些容易忽略的地方。
